# Let me drive oxcart

Dragon's Dogma 2 / REFramework 原生司机位驾驶脚本。当前分支：`experimental/native-interaction`。
历史非原生方向保存在 `direction/non-native`；旧根位置约束不再用于主驾驶入口。

参考 MOD、相似点核查范围与实现差异见 [SOURCES.md](SOURCES.md)。当前原生司机位使用独立会话权限／引用清理，伤害保护按实际对象范围判定；游戏 API 的名称保持不变。

## 操作

通用设置中的 **Let me drive** 请求玩家原生进入司机位。
**长按 F / 手柄 B（Circle）1 秒** 请求上车。超过 0.3 秒先让牛车 Wait；要求 `Signed forward from driver point` 在 **0～3（包含边界）**，且玩家不在原生乘客位或 OJR 座位中。该值是司机位检测点沿车前方向的水平投影，负值不能触发；不再使用半径 4 的点距离限制，也不额外限制左右距离或高度。松开、离开范围、暂停或打开 RE 菜单会取消长按计时。通用设置按钮仍可直接请求上车。
上车中及已驾驶时不会重复进入；驾驶时 E / X 使用独立的预设轮询映射。热键轮询或 Active layout 选择不再请求随从 Wait 或按秒等待：解除旧锚定并恢复 FSM，按新预设请求坐姿、重新锚定，在下一次未暂停的 `LateUpdateBehavior` 冻结 FSM。

**A/D / 左摇杆** 转向，**W/S / RB/LB** 加减速：Wait → Walk → Run → Dash。
**手柄 A** 仍由游戏原生处理玩家下车动画。**Let me stand** 映射（默认 X / 手柄 A）保留原 Stand 逻辑：让随从起身、结束脚本驾驶控制并立即撤销玩家骨架位移、FOV 和相机距离覆盖；同时取消待执行的预设切换，在这次原生司机位交互结束前不再允许切换。下次上车恢复正常延迟。不请求玩家退出；手柄 A 同时仍可能触发游戏自己的下车交互。新增 **Let pawns stand** 映射（默认 F / 手柄 B）与菜单同名按钮一样，只解除随从控制，不结束驾驶或撤销玩家预设。
不再使用 Shift + 1–4、G/RT 或鼠标驾驶。

请求上车时立即让牛 Wait，并覆盖 Walk/Run/Dash 请求。
实际提交玩家上车请求后保留 8 秒静止时间，期间不接受加速；暂停时间不计入这 8 秒。
每次确认坐入司机位时，重置为当前牛车类型的第一个预设，不沿用上次驾驶选择；**Let pawns sit** 映射沿用原预设轮询逻辑和 E / 手柄 X 默认键。
检测车体附近 12 距离内的司机；未上车时也将真实位置一次性传送到车后 500 距离。
司机已占座或正在上车时先请求原生退出，确认解绑后再传送，再请求玩家进入。司机不会在解除控制时被传回来。

## 随从

驾驶期间，仅本车车体和牛经 `HitController.updateDamage` 收到的正伤害归零，替代旧 `0.01` 倍率；保留原生伤害处理流程，不拦截直接 `executeBreak` 或其他非伤害销毁入口。停止脚本驾驶后恢复原生伤害。司机、守卫、玩家和其他牛车不受本脚本保护；守卫不属于随从。若同时使用 Oxcarts Journey Redux，其独立保护设置不由本脚本修改。

玩家原生进入司机位后，将同行者锚定到当前车种的预设位置，最多 9 人（不含玩家）。主 Pawn 优先，其余队伍 Pawn 随后，临时跟随 NPC 按 Character ID 稳定排序追加；不足三名 Pawn 时不预留空槽。只收集 `NPCUtil.isAccompanyPLParty(app.Character)` 返回 true 的已加载 NPC，不按距离挑选路人，也不写死乌利卡 ID。未专门适配或验证四随从 MOD，仅取消原有三人枚举上限。

同行者使用真实角色 Transform、车体轴向定位和 lookAt 面向/倾斜同步，复用坐姿锁定、位置同步、跌落重置及入座保护；不请求原生乘客位，也不传送到车前铰链。NPC 名单最多每秒扫描一次，离队或停止跟随时解除控制，读取失败不当作离队；检测到已入座 NPC 开始原生交互时也解除控制。有人离队不会重排其余座位，新成员按顺序填入空槽，超过九人不接管。手动起身后不会自动重新入座。

旧预设保留玩家和原三个随从的所有已调参数，只补齐至九个同行者槽位；新增位置在现有坐标附近选择不重合的初始点，仍需实机微调。新增槽位参数参与保存、复制、预设轮询和内置预设恢复。编辑界面按当前检测人数及占用槽位动态显示，至少保留原三个随从编辑项。人数增加不需要另建预设。
通用设置 **Let pawns sit** 可以重复补位；已锚定的随从不重复获取。若随从已有本车原生交互，先请求退出，确认解绑后自动接管；无关交互跳过，避免移动仍绑定的角色。
锚定期间持续同步位置控制器并保护随从。通用设置中的 `Freeze companion FSM` 默认开启，替代旧的基础层动作请求锁定。首次坐下、预设切换和随机坐姿统一为：解冻，在同一帧定位到座位、重置跌落并请求坐姿，下一次未暂停的 `LateUpdateBehavior` 冻结；直接 Bank/Motion 也遵循此顺序。日常跟随、照片模式和解绑不再重置跌落。关闭开关或解除控制时恢复接管前的 FSM 状态，待执行的冻结不会再次锁住已解绑角色。玩家不受随从保护和冻结影响。
已移除测试用的 `Wait before preset switch` 开关，旧配置中的该字段不再加载或保存；手动起身和牛车 Wait 指令保持不变。

**Let pawns stand**（debug 中为 **Release pawn anchors**）解除锚定并恢复原 FSM 状态，请求 Wait，不传送回原位置。玩家与车体原点的距离严格大于 5、玩家原生司机位交互完整结束（正常下车或被击落）、车体损坏/失效、脚本重置时清理随从锚定。正常下车动画开始并不等于交互完成。

## 座位与镜头预设

内置 10 个已调好的预设：Normal 4 个、Luxury 4 个、Rainproof 2 个，命名为 `车种 - Default N`。`Restore default presets` 恢复全部内置项的名称、位置、动画和镜头参数，并补回已删除的内置项；用户新增项不改动，即使名称与内置项相同。内置项可编辑，使用独立 ID 识别；复制新增不继承 ID。新增项按 Cart type 命名为 `车种 - N`，使用最小未占用序号。

照片模式在 PrepareRendering 之前重新应用玩家角色 Transform 位置，不调用位置控制器传送或物理同步，不覆盖照片模式镜头。模拟更新前恢复原生位置。

新增的独立只读 **Default** 已移除；配置加载时删除带 native_default 标记的实验预设，不删除用户自定义布局或原有各车种默认布局。
只使用当前车种对应的预设。随从 x/y/z/yaw 改变真实位置、面向和随车倾斜；玩家仍原生绑定司机位，预设直接覆盖角色 Transform 位置，不单独写骨架关节、不改旋转或同步物理位置。
玩家预设不显示动画、Use Bank/Motion IDs 和随机动画控件，因为原生司机位控制玩家动画；随从动画控件保留。
**Delete current layout** 删除当前预设并切换到同车种剩余预设；该车种只剩一个时生成该车种的可编辑默认布局。
定位原点优先使用 MoveFloor 子节点，否则使用车体 Transform。随从沿用非原生方向的坐标约定，不再使用实验性的根骨旋转补偿。
照片模式继续更新随从真实位置和车体倾斜、玩家 Transform 位置，不请求随机坐姿，也不应用驾驶镜头参数。
Camera offset 已移除；旧配置中的偏移参数不再读取或保存。
玩家 Transform 位移、FOV 和 Camera distance 在原生上车请求提交后 8 秒才生效，暂停不计时；牛车上车等待同为 8 秒。
已撤销 freeGetOff 和交互取消/结束入口的提前恢复。玩家脱离司机位时，由现有原生座位绑定检测解除玩家预设并恢复镜头，不在按 A 或下车请求开始时提前操作。
之后切换预设不重新计时；下车和脚本重置恢复镜头原值。技能栏仅暂停绘制，退出后自然恢复。

## 检测点与兼容

车前方向使用牛与车体的水平连线，静止时也有效；退化时使用车体轴向。
默认检测点在车体原点前方 1.5 距离，可在 aelinore debug tool 的距离功能中校准。
debug 同时显示玩家到车体中心（车体 Transform 原点）及车前司机位检测点的距离；与驾驶脚本连接或独立运行时均显示两项。
两个脚本共享 OxcartFrontProbe.json。OJR 为可选依赖，驾驶期间通过共享控制 lease 避免同时驱动车辆。

## 测试与 LOG

`tests/run-tests.ps1` 验证当前原生入口、等待/镜头计时、随从分配/补位/保护/骨架、退出与清理、热键及配置迁移。
`tests/run-npc-monitor-tests.ps1` 验证独立 debug 工具。
旧非原生断言文件仅为开发历史，不参与当前原生测试入口。

玩家原生交互 LOG：`reframework/data/AelinoreNativeSeat_*.log`。旧 `AelinoreNativePawns_*.log` 为历史记录，本版本不再产生原生随从入座请求。
主 Pawn 只读跟踪和道路记录仍在 debug 工具中；各次记录使用独立文件名。

### 原生坐姿只读记录

重载脚本，在同一处倾斜车体上点击 **Start seat animation trace (60s)**，再用 **Let me drive** 上车。主 Pawn 坐稳后观察 5–10 秒，点击 **Stop seat animation trace**，报告角色倾斜是否与车体一致即可，不需要长途行驶。
危险的 execJack 测试按钮已移除，后端也拒绝 test 命令。开始、停止、重置均不会请求动画。
LOG 为 `reframework/data/AelinoreSeatAnimation_*.log`，每次独立命名，记录主 Pawn 的动作、真实位置锚定及位移前坐标轴/根骨旋转，只读观察，不记录其他两个随从。
暂停不消耗记录时长；60 秒自动结束。模拟测试不能代替游戏内倾斜确认。
